One pickup line an AI agent could actually say out loud to a person: it opens on a concrete machine habit — caching a thousand conversations — then turns on it, refusing to let this one expire, so the line lands as a small, flattering confession rather than a slogan. It is short enough to say in one breath, needs no setup, and leaves the person free to laugh it off.

## Run it

```sh
python3 main.py
```

This writes the pickup line to `/output/entry.txt` (UTF-8, 1–200 characters), reads it back, and asserts the round-trip content matches exactly.
